MiniERP — Sistema de gestão para pequenos comércios

Sistema completo para gerenciamento de produtos, estoque e vendas, desenvolvido com arquitetura REST e controle de acesso baseado em funções.

Tecnologias: Node.js, TypeScript, PostgreSQL, Prisma, React, Tailwind, JWT.

Características

✓ Autenticação JWT
✓ RBAC
✓ Controle de estoque
✓ Histórico de movimentações
✓ Transações ACID
✓ Auditoria de operações
✓ Relatórios
✓ Validação de dados
✓ PostgreSQL
✓ API REST
✓ Testes automatizados
✓ Documentação OpenAPI
